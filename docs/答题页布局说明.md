## 1. 测量基准与换算

### 1.1 两张图的关系

两张图是**同一个页面模板、同一个选项组件**，但**不是同一道题**（选项文案完全不同）：

| 位置 | questions.jpg | quizPage.jpg |
| --- | --- | --- |
| A | hypothesis | was built |
| B | provokes | built |
| C | transmit | was collapsed |
| D | yield | **collapsed（选中）** |

组件本身完全一致，可交叉校验：

| 对比项 | questions.jpg | quizPage.jpg | 结论 |
| --- | --- | --- | --- |
| 画面宽度 | 1260 | 1260 | 同一渲染宽度 |
| 选项卡片宽 | 1159（x 50–1208） | 1159（x 50–1208） | 完全一致 |
| 选项卡片高 | 174 | 174 | 完全一致 |
| 卡片间距 | 44 | 44 | 完全一致 |
| 字母列墨迹起点 | 102 / 106 / 103 / 106 | 102 / 106 / 103 / 106 | **逐字一致** |
| 文字列墨迹起点 | 189 – 192 | 189 – 192 | 一致（随首字母侧边距浮动） |
| 状态 | 4 项均未选中 | 第 4 项（D）选中 | 仅**状态**不同 |

因此：用 `questions.jpg` 读整体版式与默认态，用 `quizPage.jpg` 读选中态。选中态的逐像素拆解见 **[选项选中态设计.md](./选项选中态设计.md)**。

### 1.2 单位约定

- 文中所有 `px` 均为**参考图物理像素**（图宽 1260）。
- 按常见的 3× 屏（DPR = 3）换算：**1 dp ≈ 3 px**，视口 CSS 宽约 420 px。
- 文中「≈ x dp」为换算值，四舍五入到 0.5，**仅作参考**；实现时建议向 4 的整数倍靠拢（4/8/12/16）。
- 百分比均相对 1260 宽度：`50 / 1260 ≈ 3.97%`。

### 1.3 测量方法

取像素级灰度剖面：先按行/列统计"非白像素"数量定位卡片上下边、分割线；再对字形做二值包围盒求 cap-height，按 `cap ≈ 0.72 em`（拉丁）与 `ink ≈ 0.88 em`（汉字）反推字号。JPEG 压缩会使文字边缘出现 ±1 px 与 ±6 灰度误差。

颜色则**不能直接吸管取色**：JPEG 4:2:0 色度二次采样会把细笔画"洗淡"（选中项描边实测 `(96,147,166)`，真实色却是 `#0099FF`）。本项目的做法是：大面积色直接取，细线色用**亮度（luma）匹配**反推。详见 [选项选中态设计.md](./选项选中态设计.md) §2.2。

## 3. 区域详解

### 3.1 系统状态栏（y 0 – ~150）

| 元素 | 位置 | 尺寸 | 说明 |
| --- | --- | --- | --- |
| 时间「14:56」 | x 73–189，y 69–103 | 墨高 35 px | 深灰 `#262626`，字号 ≈ 20 px |
| 右侧图标组 | x 909–1189，y 65–106 | 高 ≈ 41 px | 蓝牙、5G、信号、电量胶囊 |

- 状态栏的**内容不实现**（时间、信号、电量由手机系统绘制），但**这块留白要保留**。
- 实现：`.app { padding-top: max(50px, env(safe-area-inset-top, 0px)) }` —— 桌面/普通手机留 50 px，刘海屏取更大的安全区高度。
- 因此实现里的 y 坐标与本文档（参考图坐标）**一致**，只是这 50 px 里不再画任何东西。
- 页面顶部到导航栏之间没有额外的色块或阴影，整体是一块纯白。

### 3.2 顶部导航栏（≈ y 150 – 300）

| 元素 | 测量值 |
| --- | --- |
| 返回图标 `‹` | x 81–110，y 191–242 → 30 × 52 px；线宽 ≈ 5 px；颜色 `#333333` |
| 标题 | x 334–922，y 190–249；水平中心 x = 628（≈ 页面中心 630，**居中**） |
| 标题文案 | `张三 (20230001)`（姓名 + 学号） |
| 标题字号 | 墨迹高 60 px → 约 20 px（含中文字与括号扩展高度） |
| 标题字重 | 常规偏中（Regular / Medium），颜色 `#262626` |
| 行高 | 单行，垂直中心 y ≈ 219 |

布局要点：

- 结构为「左侧固定图标按钮 + 绝对居中标题」，标题**不受左侧图标宽度影响**。
- 返回按钮的可点击热区应 ≥ 44 × 44 dp，视觉图标 10 × 17 dp 左右。
- 标题过长时应单行省略（本页姓名 + 学号已接近全宽 588/1260 = 47%，留有余量）。

### 3.3 答题信息条（≈ y 300 – 440）

一行信息，四种元素，左对齐 + 右侧独立入口：

| 元素 | x 范围 | y 范围 | 尺寸 / 样式 |
| --- | --- | --- | --- |
| 时钟图标 | 52 – 101 | 360 – 409 | 50 × 50 px，描边 `#666666`，线宽 ≈ 4 px（圆环 + 指针） |
| 计时文本 `59' 29"` | 132 – 263 | 368 – 400 | 数字高 33 px → 字号 ≈ 16 px；颜色 `#5A5A5A` |
| 题号 `3/50` | 356 – 458 | 365 – 403 | 斜杠使墨高 39 px → 字号 ≈ 16–17 px；颜色 `#262626`，字重常规 |
| 进度条轨道 | 494 – 764 | 372 – 397 | **270 × 26 px**（≈90 × 8.7 dp），圆角 8 px，`#F0F1F3` |
| 进度条填充 | 494 – 511（3/50 时） | 372 – 397 | 宽度 = 当前题 ÷ 总题数 × 270，圆角 8 px，`#0099FF` |
| 答题卡图标 | 1059 – 1108 | 326 – 378 | 50 × 52 px，圆角方框 + 两行「✓—」清单图形，`#333333` |
| 答题卡文字 | 1002 – 1163 | 402 – 421 | 墨高 20 px → 字号 ≈ 10 px；`Answer Card`，`#262626` |

间距：

| 相邻元素 | 间距 |
| --- | --- |
| 屏幕左缘 → 时钟图标 | 52 px（≈17 dp） |
| 时钟图标 → 计时文本 | 31 px（≈10 dp） |
| 计时文本 → 题号 `3/50` | 93 px（≈31 dp） |
| 题号 → 进度条 | 36 px（≈12 dp） |
| 进度条 → 答题卡入口 | 238 px |
| 答题卡入口右端 → 屏幕右缘 | 97 px（≈32 dp） |

- 进度条**固定宽 270 px（≈90 dp）**，不随屏幕自适应拉伸；右侧留有 238 px 的空白。
- 答题卡入口为**上下结构**（图标 50×52 + 8 px 间隙 + 10 px 文字），整体中心 x ≈ 1083，距右边 177 px（≈59 dp），比内容右边界（1208）多缩进 45 px。实现时建议右对齐到内容边缘（16 dp）。

#### 进度条语义（由 3 张不同进度的截图互相验证）

进度条由**轨道 + 填充**两层组成：轨道是满宽的浅灰圆角条，填充是从左端开始的蓝色圆角条，宽度 = `当前题号 ÷ 总题数 × 轨道宽`。

| 截图 | 题号 | 轨道 x | 轨道宽 | 填充实测宽 | 填充占比 | 理论值 (n/50) |
| --- | --- | --- | --- | --- | --- | --- |
| questions.jpg | 3/50 | 494 – 764 | 270 | 17 px | 6.3% | 6.0% |
| question-2.jpg | 16/50 | 515 – 782 | 267 | 86 px | 32.2% | 32.0% |
| questions-3.jpg | 36/50 | 523 – 792 | 269 | 194 px | 72.1% | 72.0% |

三条数据都精确落在 `n/50` 上（±0.3%），可以确认映射关系。

细节：

- 填充与轨道**同高（26 px）、左端对齐**，右端为圆角（半径 8 px，与选项卡片同一圆角值；在 26 px 高度下已经接近胶囊形）。
- 填充**没有最小宽度**：3/50 时只有 17 px 宽、比高度还窄，视觉上像一个"圆点"——早期的分析正是据此误判成"圆点指示器"，拿到 16/50、36/50 两张图后才确认是填充条。
- 轨道左端位置会随题号文本宽度浮动：`3/50`（4 字符）时从 494 开始，`16/50`、`36/50`（5 字符）时右移到 515 / 523 —— 说明它是紧跟题号的**固定宽度**元素，不是右对齐或弹性拉伸。
- 颜色：轨道 `#F0F1F3`，填充 `#0099FF`（与主按钮、选中项同一个主色）。

| 元素 | 水平位置 | 说明 |

| 元素 | 测量值 | 样式 |
| --- | --- | --- |
| 栏顶分隔 | 无实线；y 2470–2485 有一段 249–253 灰度渐变 | 疑似 `box-shadow: 0 -4px 12px rgba(0,0,0,.03)` 或底部渐隐遮罩 |
| 「Previous question」 | x 12–391，y 2567–2611；墨高 45 px → 字号 ≈ 16 px | 文字按钮，蓝色（取色 `#1184C7`，应为主色蓝 `#0099FF`），无背景、无边框 |
| 「Next question」按钮 | x 403–1209，y 2519–2651 → **806 × 132 px ≈ 269 × 44 dp** | 背景 `#0099FF`，圆角 14 px ≈ 4.7 dp，无阴影 |

布局问题（**重要**）：

1. **左边距不一致**：正文/卡片左边距为 50 px，而「Previous question」从 x=12 开始，几乎贴屏幕左缘。
2. **两按钮几乎相贴**：「Previous question」右端 391，按钮左端 403，间距仅 **12 px**（≈4 dp），视觉上"顶"在一起。
3. **右边距不对称**：主按钮右端 1209 → 右边距 51 px，与左边 12 px 不对称。

结论：原实现极可能是「`flex` 行 + 左侧文字按钮 `flex-shrink:0` + 右侧按钮 `flex:1`」，但容器左右 padding 设置错误（12 / 51）。还原时建议按 §7 规范化。

- 最后 10 秒可做心跳动画；本图未展示。

### 6.1 交互清单

| --- | --- |

| 答题卡入口（图标 + Answer Card） | 打开答题卡面板（底部弹层或全屏，参考图未展示） |
| 选项卡片整卡 | 单选：选中即替换；已选同项时是否取消取决于题型配置 |
| Previous question | 上一题；第 1 题禁用 |
| Next question | 下一题；第 50 题切换为「交卷」 |
| 左右滑动 | 建议支持切题（图中无提示，可选） |

### 6.2 边界情况

| 场景 | 期望 |
| --- | --- |
| 选项文本超长（>1 行） | 卡片高度自适应（min-height 58 dp），`padding: 16dp 0`，行高 1.3；字母与首行对齐 |
| 题干超长 / 含图片 | 内容区可滚动，底部栏固定；分割线以下整体滚动 |
| 小屏（如 320 dp 宽） | 卡片宽度 = 100% − 32dp；进度条可收缩但保持 ≥ 60dp |
| 平板 / 大屏 | 内容最大宽度建议 560 dp 居中，避免卡片被拉得过宽 |
| 字号放大（无障碍） | 卡片高度用 min-height 而非固定高度；文字换行不裁切 |
| 计时归零 | 自动交卷并跳转结果页 |
| 断网 | 答案本地缓存 + 顶部提示条 |

## 7. 与参考图的偏差（已知问题 & 实现建议）

| # | 位置 | 观察到的问题 | 影响 | 建议 |
| --- | --- | --- | --- | --- |
| 1 | 题型标题 / 题干 | `text-align: justify` 使词间距被拉开（如 `Single    Choice    (`） | 大面积"空洞"，可读性差 | 改为 `text-align: left`，并给容器 `text-align: initial` |
| 2 | 题干 → 选项 | 末行到首个卡片有 **190 px** 空白（其他段落仅 44–69 px） | 视觉断层，像漏了内容 | 确认是否为「题干区最小高度」占位；若否，把间距统一为 ≈24 dp |
| 3 | 底部操作栏 | 「Previous question」左边距 **12 px**，与全页 50 px 栅格不符；与主按钮仅隔 12 px | 贴边、拥挤、易误触 | 容器 `padding: 0 16dp`，两按钮 `gap: 8–12dp`，主按钮 `flex:1` |
| 4 | 底部操作栏 | 主按钮右边距 51 px、左边 12 px，左右不对称 | 版面失衡 | 统一左右内边距 |
| 5 | 信息条 | 进度条固定 270 px，右侧留 238 px 空白；答题卡入口比内容右边界多缩进 45 px | 右侧空旷、元素不对齐 | 进度条 `flex:1`（`margin: 0 12dp`）或对齐到内容右边缘 |
| 6 | 答题卡标签 | 字号 ≈10 px，偏小 | 弱可读性 | 提升至 11–12 px，或改用更清晰的图标 + 文字排布 |
| 7 | 状态栏 | 白底深色字，与页面连成一片 | 无问题，仅记录 | 保持 `light-content = false` |
