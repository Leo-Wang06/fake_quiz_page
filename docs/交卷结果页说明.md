## 1. 先说一个容易误判的点：这张图是「裁过的」

`finished.jpg` 顶部没有系统状态栏，直接从导航栏开始——但**并不是这个页面没有状态栏**，而是截图把状态栏那一截裁掉了。证据：

| 参照物 | 答题页 `questions.jpg` | 结果页 `finished.jpg` |
| --- | --- | --- |
| 图片高度 | 2750 px | 2596 px |
| Home Indicator y | 2711 – 2725 | 2557 – 2571 |
| 差值 | — | **正好 154 px** |

`2596 + 154 = 2750`，且两个页面的 Home Indicator 绝对位置一致 → 结果页就是同一块 917 CSS px 高的屏幕，只是把顶部 154 px（≈51 CSS，状态栏高度）剪掉了。

**结论**：结果页截图是同一块 917 CSS px 高的屏幕，只是顶部被剪掉了。下文的坐标都按「导航栏顶部 = 0」计。

> 实现上**不绘制**状态栏内容（真机自带），但保留同样高度的顶部留白：`.app { padding-top: max(50px, env(safe-area-inset-top, 0px)) }`，因此导航栏的位置与参考图一致。

## 5. 实现要点

```css
/* 答题页与结果页都是 .app 下的 .view，二选一显示 */
.view { flex: 1; min-height: 0; display: flex; flex-direction: column; }
.view[hidden] { display: none; }

.fcard { margin: 14.8px 44.67px 0; padding: 12.6px 17.7px 10.8px;
         border-radius: 4px; background: #F7F8FA; }
.fcard__row { display: flex; align-items: center; height: 35px;
              font-size: 16.7px; color: #8E8E93; }

.fhint { margin: auto 0 0; padding-bottom: 95.3px;
         font-size: 16.2px; color: #86868B; text-align: center; }
```

- 底部说明用 `margin-top: auto` 顶到最下方，再用 `padding-bottom` 控制与屏幕底的距离。
- 时间戳用 `font-variant-numeric: tabular-nums`，秒数跳动时宽度不抖。
- 结果页不需要滚动，整页固定高度。
